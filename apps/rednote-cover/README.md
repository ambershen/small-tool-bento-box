# Rednote Cover Studio

A standalone Vite + React workspace for designing Rednote/Xiaohongshu cover images.

## Features

- 2:3 Rednote-style canvas for 1080 × 1620 exports.
- Upload a background image or start from atmospheric preset backgrounds.
- Drag text blocks directly on the HTML canvas.
- Edit copy, font mood, color, alignment, size, rotation, position, line height, grain, and photo tone.
- Download the composed cover as a PNG.

## Run

```bash
npm run dev -w @smalltool/rednote-cover
```

## Build

```bash
npm run build -w @smalltool/rednote-cover
```
